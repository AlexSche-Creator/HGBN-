# HGBN — дневник самонаблюдения

iPhone-приложение для быстрой фиксации эпизодов напряжения и тревоги:
интенсивность, причины, длительность и статистика. По духу близко к Daylio,
но специализировано под эпизоды, тревогу и аналитику состояния.

> Приложение — это дневник самонаблюдения и аналитики. Это **не** медицинский
> инструмент: в интерфейсе нет диагнозов, советов и драматизации.

## Возможности

- ⏱ Фиксация эпизода за пару касаний: «Начался» → таймер → «Завершить».
- ✍️ Ручное добавление эпизода задним числом (1 минута … 5 часов + «весь день»).
- 😮‍💨 Отдельная фиксация тревоги, опционально связанная с эпизодом.
- 📅 Календарь состояний с иконкой статуса каждого дня.
- 📊 Статистика за день / неделю / месяц / год: графики, топ причин, серии,
  распределение по времени суток, корреляция тревоги и напряжения.
- ⚙️ Управление причинами, настройка порогов оценки дня, тема, напоминания.
- 📤 Экспорт в JSON/CSV в структуре, готовой для загрузки в DWH.

## Стек

- iOS 17+, Swift 5, SwiftUI
- SwiftData (локальное хранилище, офлайн-first)
- Swift Charts (графики)
- UserNotifications (вечернее напоминание)

## Как запустить в Xcode

1. Откройте `HGBN.xcodeproj` в **Xcode 16** или новее.
2. Выберите схему **HGBN** и симулятор iPhone (iOS 17+).
3. Нажмите **Run (⌘R)**.

При первом запуске хранилище наполняется 20 быстрыми причинами по умолчанию
(10 для напряжения, 10 для тревоги). Демо-данные подключаются только в
SwiftUI Preview, реальное хранилище стартует пустым.

> Проект использует file-system-synchronized группы Xcode 16 — новые файлы в
> папках `HGBN/` и `HGBNTests/` подхватываются автоматически, без правки
> `project.pbxproj`.

## Тесты

- В Xcode: **Product → Test (⌘U)**.
- Из терминала:

```bash
xcodebuild test \
  -project HGBN.xcodeproj \
  -scheme HGBN \
  -destination 'platform=iOS Simulator,name=iPhone 15'
```

Покрыта бизнес-логика `DayStatusCalculator`: все границы статусов
(супер / хороший / так себе / тяжёлый / очень тяжёлый), ручное
переопределение и расчёт метрик.

## Логика оценки дня

`DayStatusCalculator` принимает эпизоды и записи тревоги за день и возвращает
`dayStatus`, иконку, метрики и текстовое резюме. Пороги настраиваются в
`DayThresholds` (Настройки → Пороги оценки дня) и по умолчанию:

| Статус | Условия (упрощённо) |
|--------|---------------------|
| Супер | 0 эпизодов, либо 1 короткий (≤15 мин) и слабый (≤5) |
| Хороший | 2–5 коротких слабых, либо суммарно ≤60 мин и макс. ≤5 |
| Так себе | >5 эпизодов, либо суммарно >60 мин, либо интенсивность 6–7 |
| Тяжёлый | интенсивность 8–9, либо один эпизод >2 ч, либо суммарно >3 ч |
| Очень тяжёлый | интенсивность 10, флаг «весь день», либо суммарно >5 ч |

Подробнее об архитектуре и DWH — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
и [`docs/DWH.md`](docs/DWH.md).
