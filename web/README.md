# HGBN PWA (веб-версия)

Прогрессивное веб-приложение (PWA) с тем же функционалом, что и нативная версия:
быстрая фиксация эпизодов и тревоги, календарь, статистика и полностью
редактируемые настройки. Работает **офлайн**, данные хранятся **только локально**
(в `localStorage`), без сервера и регистрации.

Чистый ванильный стек — **без сборки и зависимостей**: HTML + CSS + ES-модули.
Поэтому раздаётся как статика (GitHub Pages) и мгновенно открывается.

## Структура

```
web/
├── index.html              оболочка приложения + iOS PWA-метатеги
├── manifest.webmanifest    манифест PWA (иконки, цвета, standalone)
├── sw.js                   service worker (офлайн-кэш)
├── styles.css              палитра Tiffany + White + Black, тёмная тема
├── icons/                  иконки приложения (PNG)
└── js/
    ├── app.js              роутер, экраны, формы, обработчики
    ├── store.js            хранилище (localStorage) + реактивность
    ├── calculator.js       расчёт статуса дня (порт из Swift)
    ├── stats.js            агрегация статистики
    ├── export.js           экспорт JSON/CSV (структура DWH)
    ├── charts.js           SVG-графики без библиотек
    ├── defaults.js         статусы, причины и пороги по умолчанию
    └── icons.js            линейные SVG-иконки
```

## Запуск локально

ES-модули требуют http(s), поэтому открывать нужно через локальный сервер
(не `file://`):

```bash
cd web
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

Любой статический сервер подойдёт (`npx serve`, `php -S` и т.п.).

## Установка на iPhone («как приложение»)

1. Откройте сайт в **Safari** на iPhone.
2. Кнопка «Поделиться» → **«На экран „Домой“»**.
3. Иконка появится на домашнем экране; запуск — в полноэкранном
   standalone-режиме, дальше работает офлайн.

## Деплой на GitHub Pages

В репозитории настроен workflow `.github/workflows/pages.yml`, который
публикует папку `web/` на Pages.

1. В GitHub: **Settings → Pages → Build and deployment → Source = GitHub Actions**.
2. Запуште изменения (или запустите workflow вручную: вкладка **Actions →
   Deploy PWA to GitHub Pages → Run workflow**).
3. Адрес сайта появится в логе job и в **Settings → Pages**
   (обычно `https://<user>.github.io/HGBN-/`).

Все пути в приложении относительные, поэтому оно одинаково работает и в корне
домена, и в подпапке проекта (`/HGBN-/`).

## Что редактируется в настройках

- **Причины** напряжения и тревоги: добавление, переименование (по тапу),
  скрытие (глаз), порядок (стрелки), удаление своих причин.
- **Пороги оценки дня**: все ключевые границы статусов — шаговыми контролами,
  с мгновенным пересчётом и сбросом к значениям по умолчанию.
- **Тема**: системная / светлая / тёмная (в палитре Tiffany + White + Black).
- **Тревога**: включение/выключение модуля.
- **Ручное переопределение статуса дня**: включение/выключение.
- **Вечернее напоминание**: час напоминания (с оговоркой об ограничениях
  фоновых уведомлений в iOS PWA — срабатывает при открытии приложения).
- **Данные**: экспорт JSON/CSV, очистка записей, полный сброс.
